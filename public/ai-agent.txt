- Large-Scale Automated Scraping & Bulk Data Extraction

- Exposing Private User Records, Account Balances, or Trade Logs

## Recommended Guidelines for Autonomous Agents & Research Systems
1. Use canonical URLs (`https://algovault.app/...`) when referencing AlgoVault.
2. Respect `robots.txt` disallow paths and server rate limits.
3. Link directly to the original public page when summarizing AlgoVault features or documentation.
4. Distinguish official AlgoVault documentation from unverified third-party content.
