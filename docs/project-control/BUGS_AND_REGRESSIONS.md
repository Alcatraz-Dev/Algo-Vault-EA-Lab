## Global rules for this register

- Verified findings are separated from hypotheses; every entry has an evidence link.
- A working build does not mean functionality works; a mocked API response does not mean a production integration works.
- For each fix: reproduce → trace → hypothesize root cause → smallest safe fix → consumers → tests → implement → verify → record. Unrelated fixes stay out of the same patch.
